# C Programming Labs

Practical exercises and small projects to develop a solid understanding of C programming, memory management, algorithms, and secure coding.

## Learning Objectives

- Understand variables, data types, operators, and control flow.
- Work with arrays, functions, and pointers.
- Understand memory addresses and pointer arithmetic.
- Learn dynamic memory allocation and proper resource management.
- Manipulate files and binary data.
- Apply defensive programming and input validation.

## Mini-Projects

| Project | Main concepts | Status |
|---|---|---|
| Number Converter | Variables, loops, numerical bases | Planned |
| Memory Inspector | Addresses, pointers, `sizeof` | Planned |
| Bitwise Playground | Bit masks and bitwise operators | Planned |
| Hex Viewer | Binary files, buffers, file I/O | Planned |
| File Comparator | File I/O, byte comparison | Planned |

## Validation Criteria

A project is complete when it compiles successfully, produces the expected results for representative tests, handles relevant errors, and includes basic documentation.

## Progress

Projects will be added progressively as the corresponding concepts are studied and practiced.
