# x86 Assembly Labs

Practical exercises focused on 32-bit x86 architecture, registers, instructions, stack operations, and low-level programming fundamentals.

## Learning Objectives

- Understand general-purpose registers and flags.
- Practice arithmetic and logical instructions.
- Manipulate memory addresses and operands.
- Understand conditional jumps and loops.
- Explore the stack and function calls.
- Analyze the relationship between C and machine instructions.

## Mini-Projects

| Project | Main concepts | Status |
|---|---|---|
| Register Arithmetic | Registers, MOV, ADD, SUB | Planned |
| Bitwise Operations | AND, OR, XOR, shifts | Planned |
| Conditions and Loops | CMP, conditional jumps | Planned |
| Stack Explorer | PUSH, POP, stack behavior | Planned |

## Toolchain

Assembler, linker, execution environment, and build commands will be documented for each project.

## Progress

Exercises will be introduced progressively, with an emphasis on understanding instruction behavior rather than memorizing syntax.
