# x64 Assembly Labs

Experiments and practical exercises exploring 64-bit x86 architecture, registers, memory addressing, calling conventions, and interoperability with C.

## Learning Objectives

- Understand 64-bit registers and their subregisters.
- Work with arithmetic, logical, and control-flow instructions.
- Explore stack alignment and stack frames.
- Understand x64 calling conventions.
- Practice function calls and parameter passing.
- Analyze compiler-generated Assembly from C programs.

## Toolchain

Assembler syntax, compiler, linker, and platform-specific calling conventions will be documented for each exercise.

## Progress

Projects will evolve from basic instruction experiments toward more advanced low-level programming and reverse engineering concepts.
