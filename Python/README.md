# Python Programming Labs

Hands-on exercises and mini-projects covering Python fundamentals, automation, algorithms, file processing, cybersecurity, and mathematical computing.

## Learning Objectives

- Strengthen Python fundamentals and control flow.
- Practice functions, modules, and data structures.
- Work with files, exceptions, and context managers.
- Apply type hints and write readable, maintainable code.
- Automate repetitive tasks.
- Write tests using `pytest`.
- Explore numerical programming and algorithms.

## Mini-Projects

| Project | Main concepts | Status |
|---|---|---|
| Number Converter | Functions, integers, formatting | Planned |
| Log Analyzer | Files, strings, dictionaries | Planned |
| File Organizer | pathlib, filesystem operations | Planned |
| Statistics Calculator | Lists, functions, numerical calculations | Planned |
| API Client | HTTP requests, JSON, error handling | Planned |

## Validation Criteria

A project is complete when it runs successfully, handles expected errors, includes representative tests, and provides clear usage instructions.

## Progress

Projects will be added incrementally, with increasing emphasis on testing, code organization, and maintainability.
